# Login Authentication System

1. Project Overview

This project is a simple Login Authentication System developed as part of the Oasis Infobyte Web Development Level 2 internship task.

The application provides user registration, login authentication, session-based access to a protected dashboard, and logout functionality.

2. Features

User registration
Username/Email and password validation
Minimum 8-character password requirement
Password must contain at least one number
Duplicate username/email validation
Secure password hashing using bcrypt
User login authentication
Protected dashboard using sessions
Logout functionality
JSON file used for storing user data

3.Technologies Used

4. How to Run

4.1. Open the project folder in VS Code.
4.2. Open the terminal.
4.3. Install the required dependencies using:

4.4. Start the server:
node app.js
