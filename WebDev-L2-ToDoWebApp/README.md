To-Do Web App

1. Project Overview
This project is a simple To-Do Web App developed as part of the Oasis Infobyte Web Development Level 2 internship task.

The application allows users to add and manage daily tasks by keeping pending and completed tasks organized in separate sections.

2. Features
Add new tasks
Display pending tasks
Display completed tasks
Mark tasks as completed using a checkbox
Edit existing tasks
Delete tasks
Display task creation time
Show pending and completed task counts

3. Technologies Used
HTML
CSS
JavaScript

4. How to Run
Open the project folder.
Open index.html in a web browser.
Add and manage tasks using the To-Do application.
